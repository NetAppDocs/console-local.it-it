= Porte per l'agente Console on-premises nella distribuzione locale di NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Nella distribuzione locale della NetApp Console, l'agente della Console utilizza porte _in entrata_ quando viene installato manualmente su un host Linux locale. Consulta queste porte per la pianificazione.

Queste regole in entrata si applicano a tutte le modalità di distribuzione della NetApp Console.

[cols="10,10,80"]
|===
| Protocollo | Porta | Scopo 


| HTTP | 80  a| 
* Fornisce accesso HTTP dai browser web dei client all'interfaccia utente locale
* Utilizzato durante il processo di aggiornamento di Cloud Volumes ONTAP




| HTTPS | 443 | Fornisce accesso HTTPS dai browser web dei client all'interfaccia utente locale 
|===
