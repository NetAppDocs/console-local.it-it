= Collega il tuo LLM e abilita l'assistente della NetApp Console nella distribuzione locale di NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Collega un endpoint LLM supportato per rendere disponibili agli utenti della distribuzione locale di NetApp Console le linee guida e le operazioni di storage in linguaggio naturale governate.


NOTE: Questa documentazione relativa alla connessione di un LLM all'assistente della Console per abilitare le funzionalità di intelligenza artificiale è fornita come anteprima tecnologica. Con questa offerta in anteprima, NetApp si riserva il diritto di modificare i dettagli dell'offerta, i contenuti e la tempistica prima della disponibilità generale.

.Ruoli di accesso richiesti
Super amministratore o amministratore dell'organizzazione. link:reference-iam-predefined-roles.html["Scopri i ruoli di accesso"].

Dopo la configurazione, gli utenti aprono l'assistente della Console dalla dashboard e scelgono una modalità di accesso:

* In modalità *sola lettura*, l'assistente risponde alle domande e fornisce indicazioni senza apportare modifiche.
* In modalità *lettura/scrittura*, l'assistente può intervenire sull'infrastruttura di archiviazione. Mostra i dettagli per la revisione e la conferma prima di ogni modifica. Per le operazioni asincrone, come la creazione di volumi, crea un processo che puoi controllare tramite l'assistente.


Per connettere il tuo LLM, seleziona un percorso del provider, inserisci i dettagli dell'endpoint e la chiave API, quindi seleziona un modello in *Administration > AI Tools*. Le azioni dell'Assistant rimangono all'interno delle tue policy di archiviazione e in base al ruolo dei controlli di accesso.



[[gather-what-you-need-before-you-connect-an-llm]]
== Raccogli tutto il necessario prima di connetterti a un LLM

Prepara le credenziali del provider e l'accesso all'endpoint in modo che l'assistente della NetApp Console possa operare entro i limiti di governance configurati dalla tua organizzazione.

* La tua scelta del tipo di provider: OpenAI, OpenAI-compatibile o Anthropic, come supportato dalla versione e dall'endpoint.
* Una chiave API valida per il percorso del provider che selezioni.
* L'URL dell'endpoint per il percorso del tuo provider.
* Il tuo nome utente o ID per l'account del provider LLM, se richiesto.
* Accesso alla rete dalla distribuzione locale della Console all'endpoint selezionato.


link:reference-llm-supported-models.html["Scopri i provider e i modelli LLM supportati nella distribuzione locale di NetApp Console"].



[[connect-an-llm-to-netapp-console-local-deployment]]
== Connetti un LLM alla distribuzione locale della NetApp Console

Abilita le funzionalità di assistenza tramite una configurazione del provider convalidata, mantenendo al contempo il controllo amministrativo sulle credenziali dell'endpoint.

.Passaggi
. Accedi alla distribuzione locale della NetApp Console.
. Seleziona *Amministrazione > Strumenti di IA*.
. Seleziona il menu, quindi seleziona *Modifica*.
. In *Tipo di fornitore*, seleziona un tipo di fornitore.
+
link:concept-llm-integration.html["Scopri l'integrazione di LLM nella distribuzione locale di NetApp Console"].

. Se ti viene richiesto un endpoint del provider, inserisci l'URL dell'endpoint per il percorso del provider che hai selezionato.
. Nel campo *Nome utente*, inserisci il tuo nome utente o l'SSO ID se il percorso del tuo provider lo richiede.
. Nel campo *Chiave API*, incolla la chiave API dal percorso del provider selezionato.
. Seleziona un modello dall'elenco.
. Rivedi la configurazione, quindi seleziona *Salva*.
+
Verifica il tipo di provider, l'URL dell'endpoint, la chiave API e il modello selezionato prima di salvare la configurazione.





[[verify-that-llm-integration-works]]
== Verifica che l'integrazione con LLM funzioni

Conferma la disponibilità dell'assistente e il comportamento di approvazione, così gli utenti possono fare affidamento sull'integrazione configurata per le operazioni governate.

.Passaggi
. Apri l'Assistente console in modalità Read only ed esegui una query di base.
. Apri l'Assistente console in modalità *Lettura/scrittura* e conferma che le azioni che modificano lo storage richiedano la conferma dell'utente prima dell'esecuzione.
. Verifica che gli utenti che necessitano di flussi di lavoro di azione abbiano i controlli di accesso in base al ruolo richiesti.


Dopo aver completato la convalida, gli utenti possono aprire l'assistente Console dalla dashboard e descrivere le attività in linguaggio naturale. link:task-console-asst-use.html["Scopri come utilizzare l'assistente NetApp Console"].



[[protect-credentials-and-monitor-llm-usage]]
== Proteggi le credenziali e monitora l'utilizzo di LLM

Proteggi le credenziali LLM e monitora l'attività dei provider per ridurre l'uso non autorizzato dell'integrazione e supportare la governance organizzativa.

* Quando possibile, usa una chiave API dedicata per l'integrazione della distribuzione locale della Console.
* Ruota le chiavi API in base alle policy della tua organizzazione.
* Monitora l'utilizzo delle API lato provider e gli avvisi in base ai requisiti di governance della tua organizzazione.
