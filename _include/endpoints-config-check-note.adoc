* Per le nuove distribuzioni dell'agente, NetApp controlla i seguenti endpoint: link:reference-networking-saas-console.html["elencato qui"^]. * Se aggiorni gli endpoint nel tuo firewall, gli agenti esistenti continueranno a funzionare.
